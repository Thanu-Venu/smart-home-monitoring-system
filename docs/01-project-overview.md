# Smart Home Monitoring & Control System

## Overview

The Smart Home Monitoring & Control System is a real-time mobile application that allows users to monitor and control smart home devices from anywhere.

The system consists of three main components:

- Android Mobile Application
- Firebase Backend
- Web-based Hardware Simulator

All components communicate through Firebase Realtime Database to ensure real-time synchronization.

---

## Objectives

- Monitor smart home devices in real time.
- Control electrical devices remotely.
- Support multiple floors within a house.
- Automatically enforce safety rules.
- Generate device usage reports.
- Simulate IoT devices without physical hardware.

---

## Core Features

- Multi-floor dashboard
- Device control
- Real-time synchronization
- Device scheduling
- Automatic safety cut-off
- Security camera simulation
- Notifications
- Usage analytics
