# Firebase Data Model

## Root Structure

```text
users/
homes/
floors/
rooms/
devices/
schedules/
usageLogs/
notifications/
```

## Users

Stores user account information.

## Homes

Represents each smart home.

## Floors

Stores all floors belonging to a home.

## Rooms

Represents rooms within each floor.

## Devices

Stores information about all smart devices.

Example:

```json
{
  "deviceId": "device001",
  "name": "Living Room Light",
  "type": "LIGHT",
  "status": "OFF",
  "roomId": "room001"
}
```

## Schedules

Stores automatic ON/OFF schedules.

## UsageLogs

Tracks device usage.

## Notifications

Stores notifications generated by Cloud Functions.
