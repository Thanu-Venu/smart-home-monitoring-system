Add auth, safety cutoff, and real-time smart home features; fix sync bugs

Authentication & safety:
- Add Firebase email/password authentication, scoping homes to the
  signed-in user instead of a hardcoded user ID
- Add SafetyMonitor worker to auto-turn-off devices (e.g. iron) that
  exceed their configured maxOnDurationMinutes, with a CRITICAL alert
  banner on the device card

Real-time sync & UI:
- Replace one-time fetches with live Firebase listeners across Home,
  Floor, Room, and Device screens so changes from any client appear
  without a manual refresh
- Convert the Room screen to a 2-column grid with per-room device
  summaries and safety-alert badges

Device features:
- Add manual device status simulation (ERROR/DISCONNECTED/Reconnect)
  via a per-device overflow menu, since there's no real hardware
- Add ScheduleMonitor worker to automatically turn lights on/off based
  on their configured schedule window, including midnight wraparound
- Add camera playback: a "View" button plays a device's cameraUri in
  a looping video dialog
- Add an in-app Reports screen (device/room/floor counts, breakdown
  by type, active safety alerts) reachable from each home card

Bug fixes:
- Fix duplicate cards appearing on first create for homes, floors,
  rooms, and devices: creation handlers were manually appending the
  new item to local state while the newly-added real-time listener
  also picked up the same write, causing a race that could double-add
  it. Creation handlers now rely solely on the live listener.
- Add stable key = { it.id } to all list views so Compose diffs by
  Firebase ID instead of position
- Fix missing/incorrect Compose layout-modifier imports (size, weight,
  matchParentSize) causing compileDebugKotlin failures
- Add .indexOn rule for homes/ownerId to fix a Firebase query error
  on signup
