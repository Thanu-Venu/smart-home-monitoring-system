Add per-switch control, redesign UI with branding, fix schedule override bug

Multi-Switch devices:
- Add individually addressable per-switch toggles to the device card,
  replacing the single combined on/off (spec explicitly calls out
  "individually addressable switches" for gang-box units)
- Fix editing a Multi-Switch device's switch count to actually resize
  the underlying switches list instead of just updating a number

Bug fixes:
- Fix the 15-minute safety cutoff applying to every device type
  instead of only Iron — maxOnDurationMinutes was being saved
  unconditionally regardless of type
- Fix ScheduleMonitor overriding manual light toggles: it was
  re-enforcing the schedule window every 30 seconds regardless of
  user action, so a manual override never lasted more than 30
  seconds. Now edge-triggered — only acts exactly when a scheduled
  start/end time is crossed, so manual control works in between
  while automatic on/off at the scheduled times still applies
- Fix MainActivity never actually applying the app's Compose theme,
  so no custom styling was rendering at all

UI redesign:
- Replace the default template purple with a custom Material 3 color
  palette (light + dark), WCAG AA contrast, dynamic color disabled
  for consistent branding across devices
- Replace the default Android Studio launcher icon with a custom
  house logo (vector drawables), plus a matching in-app brand mark
  on the Login/Sign Up screens
- Recolor device status text (ON/OFF/ERROR/DISCONNECTED) with four
  distinct theme colors instead of two, always paired with its
  existing text label so status is never conveyed by color alone
- Add a live dashboard summary (Floors/Rooms/Devices totals) to the
  Home screen, and give every list card a tinted background instead
  of flat white
